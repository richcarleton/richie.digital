decoder

topaz HID is the confirmed format: reports are 0x2N + N stream bytes, reassembled into 5-byte packets. topaz7 scans each report for a byte with bit 7 set followed by four 7-bit bytes: x = b1 | b2<<7, y = b3 | b4<<7, pen = b0 & mask. Offsets only apply to le16/be16 and count from the first data byte (report ID not included). If the trace looks like noise, scribble left↔right and watch which byte cells heat up.
